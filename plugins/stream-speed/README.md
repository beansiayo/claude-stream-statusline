# Stream Speed

Optional companion for Claude Stream Statusline. This plugin observes the main conversation's streaming output, times the interval from the first non-empty output event to the stop event, and divides API-reported output tokens by that interval. It keeps the previous reading while a request streams, then writes the current outcome. Bursts, insufficient streaming evidence, interruptions, and missing usage produce explicit nonnumeric outcomes. Numeric results describe observed receive throughput, not guaranteed upstream decoding speed. Sampling requires three output events spanning at least 0.5 seconds and two gaps of at least 20 milliseconds; these checks reject obvious bursts but cannot detect all buffering. It stores only numeric measurements and the session identifier, never response text.

Requires the Claude Code hooks module API (`turn.step`, `$.env.get`, `$.fs.write`, and `$.session.id`). Validate against your own CLI before installing; interface availability can vary between distributions. Samples are written under `$CLAUDE_CONFIG_DIR/stream-speed` or `$HOME/.claude/stream-speed`. See the repository README for installation, compatibility limits, and uninstall instructions. MIT licensed.
